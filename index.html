The Android browser with Chrome extensions.

No telemetry, no big tech inside.

Download APK View source

Extensions, finally.

uBlock Origin Lite, floccus and other open-source extensions.

Yours to arrange.

Address bar on top or at the bottom, a toolbar you build button by button, a second row of buttons and tabs across the top like on a computer.

Private by default.

No telemetry, no big tech services. Aerium Guard sets privacy, security and speed in one place, and in its Privacy mode sites see a different fingerprint every session.

Take it with you.

Back up your open tabs, site permissions and settings, and bring them back on any phone.

Made for daily use.

Aerogel

Private tabs that keep nothing. Pick sites that always open there, send links from other apps straight in, and choose which extensions come along.

Always current

Built straight from Chromium with no fork in between, so Aerium stays on the same version as Chrome.

Search shortcuts

Type a short keyword in the address bar to search Wikipedia, YouTube, GitHub or any site you add.

Sleeping tabs

Tabs you have not touched in a while let go of memory, so the ones you use stay fast.

Mobile data saver

Pause images and autoplay, and ask for lighter pages, only while you are on mobile data.

Widget and video player

A home screen widget in three sizes, and a video player made for phones.

Named after aerogel.

The lightest solid there is, up to 99% air. Aerium keeps only what matters.
